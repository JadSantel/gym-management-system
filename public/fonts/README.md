# Self-hosted fonts

The active UI font is Inter Variable (upright, weights 100-900), selected by shadcn preset `b5J4p8Yqm` on November 10, 2026. `inter-variable.woff2` is the unmodified upstream font from https://github.com/rsms/inter/blob/master/docs/font-files/InterVariable.woff2. License: SIL Open Font License 1.1; see `Inter-OFL.txt`. The application makes no runtime or build-time Google Fonts request.

The previous `geist-latin.woff2` is retained from pinned Next.js 16.4.3 (`next/dist/next-devtools/server/font/geist-latin.woff2`), with its existing `OFL.txt`, for historical provenance. It is no longer loaded by the application.
