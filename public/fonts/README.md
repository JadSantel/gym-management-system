# Geist font

`geist-latin.woff2` is the unmodified Geist Latin font distributed with this repository's pinned Next.js 16.4.3 (`next/dist/next-devtools/server/font/geist-latin.woff2`). It is self-hosted so the app requires no Google Fonts request. The supplied prototype specifies Geist.
